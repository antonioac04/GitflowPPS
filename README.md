# GitflowPPS
## Descripción y Objetivos del proyecto
Este repositorio alojará un aplicativo web sencillo de una lista de tareas que permita añadir nuevas tareas, eliminar tareas y visualizar una lista actualizada de cada una de las tareas que se  añadan.
El objetivo de este proyecto es aprender y aplicar correctamente el modelo de trabajo de GitFlow.
## Tecnología utilizadas
En este proyecto se hace uso de HTML, CSS, JavaScript y PHP.
